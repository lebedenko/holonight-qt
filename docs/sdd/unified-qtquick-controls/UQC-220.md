## Reproduction and ownership

Standalone runtime ComboBox using the released provider reproduces a 28-pixel
row with 8-pixel top/bottom padding, leaving a 12-pixel content area for a
16-pixel RowLayout label. The label center is at y=16 instead of y=14.
Weather does not replace the delegate; provider ComboBox owns this mismatch.

On private headless Sway (no input automation), plain Qt/Fusion reports
useHoverEffects=true and ComboBox/row hoverEnabled=true. With the staged
HoloNight platform theme, both are false. Explicit Qt hover override restores
the flags. HoloniightTheme delegates UiEffects to the base theme, losing the
normal desktop HoverEffect. This is a provider platform-theme policy boundary,
not evidence for speculative Weather styling overrides. Evidence is retained in
umbrella `.cache/uqc220/`; original manual runs in the umbrella findings.

## Repair contract

- Preserve fixed popup row height and horizontal spacing while centering labels
  within the delegate. Keep popup geometry, selection, activation and RTL behavior.
- Advertise the desktop HoverEffect through the platform theme while retaining
  other base effect flags. Do not override explicit application/Qt hover settings.
- Do not replace Fusion controls, change public APIs, or migrate Settings controls.
- No third-party upstream investigation or manual comparison solely for deferrals.
